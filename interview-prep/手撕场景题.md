## 一、图片懒加载

### 场景
页面有 1000 张图片，一次性加载会卡爆。只加载可视区域的，滚动时按需加载。

### 实现

```js
// 方案1：IntersectionObserver（推荐）
function lazyLoadImages() {
  const images = document.querySelectorAll('img[data-src]')
  const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
      if (entry.isIntersecting) {
        const img = entry.target
        img.src = img.dataset.src
        img.removeAttribute('data-src')
        observer.unobserve(img)  // 加载后停止观察
      }
    })
  }, { rootMargin: '100px' })  // 提前 100px 开始加载

  images.forEach(img => observer.observe(img))
}

// 方案2：scroll 事件 + getBoundingClientRect（兼容性好）
function lazyLoadImagesLegacy() {
  const images = document.querySelectorAll('img[data-src]')
  const viewportHeight = window.innerHeight

  images.forEach(img => {
    const rect = img.getBoundingClientRect()
    if (rect.top < viewportHeight + 100 && img.dataset.src) {
      img.src = img.dataset.src
      img.removeAttribute('data-src')
    }
  })
}

window.addEventListener('scroll', throttle(lazyLoadImagesLegacy, 200))
```

**面试加分点：** 提 `IntersectionObserver`，对比 scroll 方案的性能优势（浏览器原生 API，不需要每次 scroll 计算 getBoundingClientRect）。

## 二、搜索建议（防抖 + 请求竞态）

### 场景
用户输入搜索关键词，实时显示建议列表。需要处理：防抖、请求竞态（旧请求覆盖新请求）、加载状态。

### 实现

```js
function createSearchSuggestion(inputEl, dropdownEl) {
  let currentRequest = null  // 记录当前请求的 abort controller

  const debouncedSearch = debounce(async (keyword) => {
    // 取消上一个未完成的请求
    if (currentRequest) currentRequest.abort()

    currentRequest = new AbortController()

    try {
      const res = await fetch(`/api/search?q=${keyword}`, {
        signal: currentRequest.signal
      })
      const data = await res.json()
      renderDropdown(dropdownEl, data)
    } catch (e) {
      if (e.name !== 'AbortError') {
        console.error('搜索失败', e)
      }
      // AbortError 是主动取消的，不需要处理
    } finally {
      currentRequest = null
    }
  }, 300)

  inputEl.addEventListener('input', (e) => {
    const keyword = e.target.value.trim()
    if (!keyword) {
      hideDropdown(dropdownEl)
      return
    }
    debouncedSearch(keyword)
  })
}
```

**面试加分点：**
- 用 `AbortController` 取消旧请求（不是忽略结果，而是真正取消网络请求）
- `AbortError` 不算错误，不需要提示用户
- 防抖 300ms 不是写死的，取决于产品要求

## 三、文件分片上传

### 场景
大文件（1GB+）上传，需要：分片、并发控制、断点续传、进度展示。

### 实现

```js
class FileUploader {
  constructor(options) {
    this.chunkSize = options.chunkSize || 5 * 1024 * 1024  // 5MB 一片
    this.concurrency = options.concurrency || 3             // 同时 3 片
    this.uploadedChunks = new Set()                        // 已上传（断点续传）
  }

  async upload(file) {
    // 1. 文件分片
    const chunks = this.createChunks(file)

    // 2. 检查已上传分片（断点续传）
    const uploaded = await this.checkUploaded(file)
    this.uploadedChunks = new Set(uploaded)

    // 3. 过滤未上传的分片
    const pendingChunks = chunks.filter((_, i) => !this.uploadedChunks.has(i))

    // 4. 并发上传（用之前学的 asyncPool）
    await asyncPool(this.concurrency, pendingChunks, async (chunk) => {
      await this.uploadChunk(file, chunk)
      this.uploadedChunks.add(chunk.index)
      this.reportProgress(file, chunk)
    })

    // 5. 全部上传完，通知后端合并
    await this.mergeChunks(file)
  }

  createChunks(file) {
    const chunks = []
    let cur = 0
    while (cur < file.size) {
      chunks.push({
        index: chunks.length,
        blob: file.slice(cur, cur + this.chunkSize),
        size: Math.min(this.chunkSize, file.size - cur)
      })
      cur += this.chunkSize
    }
    return chunks
  }

  async uploadChunk(file, chunk) {
    const formData = new FormData()
    formData.append('file', chunk.blob)
    formData.append('index', chunk.index)
    formData.append('fileHash', await this.getFileHash(file))
    await fetch('/api/upload/chunk', { method: 'POST', body: formData })
  }

  reportProgress(file, chunk) {
    const progress = (this.uploadedChunks.size / Math.ceil(file.size / this.chunkSize)) * 100
    console.log(`进度：${progress.toFixed(1)}%`)
    // 实际项目中触发 onProgress 回调
  }
}
```

**面试加分点：**
- 文件分片用 `Blob.slice()`
- 断点续传：上传前先问后端"哪些片已经有了"，跳过已上传的
- 并发控制用 asyncPool（Promise.race + 补位）
- 进度计算：已上传片数 / 总片数
- 全部上传完后要调后端接口合并分片

## 四、无限滚动列表

### 场景
滚动到底部自动加载下一页，需要处理：触底检测、加载状态、防重复请求。

### 实现

```js
function createInfiniteScroll(container, loadMore) {
  let isLoading = false
  let hasMore = true

  const observer = new IntersectionObserver(async (entries) => {
    if (!entries[0].isIntersecting || isLoading || !hasMore) return

    isLoading = true
    showLoadingIndicator()

    try {
      const result = await loadMore()
      hasMore = result.hasMore
      if (!hasMore) {
        observer.disconnect()  // 没有更多了，停止观察
      }
    } catch (e) {
      console.error('加载失败', e)
    } finally {
      isLoading = false
      hideLoadingIndicator()
    }
  })

  // 在列表底部放一个 sentinel 元素
  const sentinel = document.createElement('div')
  sentinel.className = 'scroll-sentinel'
  container.appendChild(sentinel)

  observer.observe(sentinel)
}
```

**面试加分点：**
- 用 sentinel 元素 + IntersectionObserver（比 scroll 事件高效）
- `isLoading` 防重复请求
- `hasMore` 判断是否还有数据
- 没有更多数据时 `observer.disconnect()` 释放资源

## 五、前端路由实现

### 场景
手写一个 SPA 路由：支持 hash 模式和 history 模式。

### 实现

```js
class SimpleRouter {
  constructor(mode = 'hash') {
    this.mode = mode
    this.routes = new Map()  // path → handler
    this.current = ''

    if (mode === 'hash') {
      window.addEventListener('hashchange', this.handleRouteChange.bind(this))
    } else {
      // history 模式需要拦截 a 标签点击 + popstate
      window.addEventListener('popstate', this.handleRouteChange.bind(this))
      document.addEventListener('click', this.handleClick.bind(this))
    }
  }

  route(path, handler) {
    this.routes.set(path, handler)
  }

  push(path) {
    if (this.mode === 'hash') {
      window.location.hash = path
    } else {
      window.history.pushState({}, '', path)
      this.handleRouteChange()
    }
  }

  handleRouteChange() {
    const path = this.mode === 'hash'
      ? window.location.hash.slice(1) || '/'
      : window.location.pathname || '/'

    if (path === this.current) return
    this.current = path

    const handler = this.routes.get(path)
    if (handler) handler()
    else this.routes.get('*')?.()  // 404
  }

  handleClick(e) {
    const link = e.target.closest('a')
    if (!link) return
    e.preventDefault()
    this.push(link.getAttribute('href'))
  }
}

// 使用
const router = new SimpleRouter('history')
router.route('/', () => renderHome())
router.route('/about', () => renderAbout())
router.route('*', () => render404())
```

**面试加分点：**
- hash 模式靠 `hashchange` 事件，不需要服务端配合
- history 模式靠 `pushState` + `popstate`，但刷新时需要服务端 fallback 到 index.html
- 拦截 `<a>` 标签点击是 history 模式的关键

## 六、WebSocket 断线重连

### 场景
实时聊天/通知系统，WebSocket 断了要自动重连，重连要有退避策略。

### 实现

```js
class ReconnectingWebSocket {
  constructor(url, options = {}) {
    this.url = url
    this.maxRetries = options.maxRetries || 10
    this.maxDelay = options.maxDelay || 30000  // 最大重连间隔 30s
    this.ws = null
    this.retryCount = 0
    this.manuallyClosed = false
    this.heartbeatTimer = null
  }

  connect() {
    this.ws = new WebSocket(this.url)

    this.ws.onopen = () => {
      this.retryCount = 0  // 重置重连计数
      this.startHeartbeat()
      console.log('WebSocket 已连接')
    }

    this.ws.onclose = () => {
      this.stopHeartbeat()
      if (!this.manuallyClosed) this.reconnect()
    }

    this.ws.onerror = (err) => {
      console.error('WebSocket 错误', err)
    }

    this.ws.onmessage = (e) => {
      const data = JSON.parse(e.data)
      // 处理消息
    }
  }

  reconnect() {
    if (this.retryCount >= this.maxRetries) {
      console.warn('达到最大重连次数，停止重连')
      return
    }

    // 指数退避：1s → 2s → 4s → 8s → 16s → 30s（封顶）
    const delay = Math.min(
      1000 * Math.pow(2, this.retryCount),
      this.maxDelay
    )

    this.retryCount++
    console.log(`${delay}ms 后第 ${this.retryCount} 次重连`)

    setTimeout(() => this.connect(), delay)
  }

  startHeartbeat() {
    this.heartbeatTimer = setInterval(() => {
      if (this.ws?.readyState === WebSocket.OPEN) {
        this.ws.send(JSON.stringify({ type: 'ping' }))
      }
    }, 30000)  // 30s 一次心跳
  }

  stopHeartbeat() {
    clearInterval(this.heartbeatTimer)
  }

  close() {
    this.manuallyClosed = true
    this.stopHeartbeat()
    this.ws?.close()
  }
}
```

**面试加分点：**
- **指数退避**（Exponential Backoff）：1s → 2s → 4s → 8s → 16s → 30s 封顶，避免疯狂重连
- **心跳机制**：定期发 ping 检测连接是否真的活着（有些网络环境下 onclose 不触发）
- **手动关闭标记**：用户主动关闭时不应该触发重连
- **最大重连次数**：避免无限重连浪费资源

## 七、实现一个 EventBus（发布订阅）

### 场景
跨组件通信、微前端跨应用通信。需要支持 on/off/once/emit。

### 实现

```js
class EventBus {
  constructor() {
    this.events = new Map()  // event → Set<callback>
  }

  on(event, callback) {
    if (!this.events.has(event)) {
      this.events.set(event, new Set())
    }
    this.events.get(event).add(callback)
    return () => this.off(event, callback)  // 返回取消订阅函数（类似 useEffect）
  }

  once(event, callback) {
    const wrapper = (...args) => {
      callback(...args)
      this.off(event, wrapper)
    }
    this.on(event, wrapper)
  }

  off(event, callback) {
    this.events.get(event)?.delete(callback)
  }

  emit(event, ...args) {
    this.events.get(event)?.forEach(cb => cb(...args))
  }

  clear() {
    this.events.clear()
  }
}
```

**面试加分点：**
- `on` 返回一个取消订阅函数——React useEffect 风格，比手动调 off 更优雅
- 用 `Set` 存储回调——天然去重
- `once` 用 wrapper 包一层，执行完自动 off

## 八、实现一个简单的状态管理（类 Pinia）

### 场景
手写一个响应式状态管理，支持 state/getters/actions。

### 实现

```js
import { reactive, computed } from 'vue'

function defineStore(setup) {
  let store  // 单例

  return function useStore() {
    if (!store) {
      store = setup()
    }
    return store
  }
}

// 定义 store
const useUserStore = defineStore(() => {
  const state = reactive({
    users: [],
    loading: false,
    page: 1
  })

  // getters
  const total = computed(() => state.users.length)
  const hasMore = computed(() => state.users.length < 100)

  // actions
  async function fetchUsers() {
    state.loading = true
    try {
      const res = await fetch(`/api/users?page=${state.page}`)
      state.users.push(...res.data)
      state.page++
    } finally {
      state.loading = false
    }
  }

  return { state, total, hasMore, fetchUsers }
})

// 组件中使用
const { state, total, fetchUsers } = useUserStore()
```

**面试加分点：**
- 本质是利用 Vue3 的 reactive + computed 做响应式
- 单例模式（`if (!store)`），多组件共享同一份状态
- 和 Pinia 的 composition store 思路一致

## 九、实现一个拖拽

### 场景
实现可拖拽元素，支持鼠标和触摸事件。

### 实现

```js
function makeDraggable(el) {
  let isDragging = false
  let startX, startY, offsetX, offsetY

  function getPoint(e) {
    return e.touches ? e.touches[0] : e
  }

  function onStart(e) {
    e.preventDefault()
    const point = getPoint(e)
    isDragging = true
    startX = point.clientX
    startY = point.clientY
    const rect = el.getBoundingClientRect()
    offsetX = point.clientX - rect.left
    offsetY = point.clientY - rect.top
    el.style.position = 'absolute'
    el.style.zIndex = '1000'
  }

  function onMove(e) {
    if (!isDragging) return
    const point = getPoint(e)
    el.style.left = point.clientX - offsetX + 'px'
    el.style.top = point.clientY - offsetY + 'px'
  }

  function onEnd() {
    isDragging = false
  }

  // 鼠标事件
  el.addEventListener('mousedown', onStart)
  document.addEventListener('mousemove', onMove)
  document.addEventListener('mouseup', onEnd)

  // 触摸事件
  el.addEventListener('touchstart', onStart, { passive: false })
  document.addEventListener('touchmove', onMove, { passive: false })
  document.addEventListener('touchend', onEnd)
}
```

**面试加分点：**
- mousemove/mouseup 要绑在 document 上，不是 el 上（鼠标移出 el 时仍然能跟踪）
- 兼容 touch 事件（移动端）
- `passive: false` 允许 preventDefault 阻止滚动

## 十、实现一个数据缓存层（请求缓存 + 过期机制）

### 场景
接口数据缓存，避免重复请求，支持过期时间和手动失效。

### 实现

```js
class RequestCache {
  constructor() {
    this.cache = new Map()  // key → { value, expireAt, promise }
  }

  // 带缓存的请求
  async cachedFetch(key, requestFn, ttl = 60000) {
    // 1. 检查是否有有效缓存
    const cached = this.cache.get(key)
    if (cached && cached.expireAt > Date.now()) {
      return cached.value
    }

    // 2. 如果有正在进行的请求（去重），复用同一个 Promise
    if (cached?.promise) {
      return cached.promise
    }

    // 3. 发起新请求
    const promise = requestFn().then(value => {
      this.cache.set(key, {
        value,
        expireAt: Date.now() + ttl,
        promise: null
      })
      return value
    }).catch(err => {
      this.cache.delete(key)  // 失败了删缓存，下次重新请求
      throw err
    })

    // 暂存 promise（去重）
    this.cache.set(key, { value: null, expireAt: 0, promise })

    return promise
  }

  // 手动失效
  invalidate(key) {
    this.cache.delete(key)
  }

  // 清空所有
  clear() {
    this.cache.clear()
  }
}

// 使用
const cache = new RequestCache()
const data = await cache.cachedFetch('users', () => fetch('/api/users').then(r => r.json()), 30000)
```

**面试加分点：**
- **请求去重**：同一个 key 的并发请求只发一次，后续复用同一个 Promise
- **失败清除**：请求失败时删缓存，不会让缓存卡住后续请求
- **TTL 过期**：存 `expireAt` 时间戳，比较时计算
- 这就是 React Query / SWR / VueUse 的 useFetch 背后核心逻辑

## 十一、微前端子应用通信（结合 Li People）

### 场景
你的 Li People 微前端架构中，主应用需要把 token、用户信息下发给子应用，子应用之间需要通过事件总线通信。

### 实现 — 双通道通信

```js
// === 主应用端 ===
import { startApp } from 'wujie'

function mountSubApp(name, url) {
  startApp({
    name,
    url,
    props: {
      // 通道1：Props 注入（单向数据流，适合配置/鉴权下发）
      token: userStore.token,
      userInfo: userStore.userInfo,
      env: import.meta.env.MODE,

      onUserAction: (data) => {
        // 子应用通过 window.$wujie.bus.$emit('user-action', data)
        // 触发这里
        analytics.track('user-action', data)
      }
    }
  })
}

// 监听子应用通过 Bus 广播的事件
import { bus } from 'wujie'
bus.$on('logout', () => {
  // 任一子应用触发 logout，主应用清状态并跳转
  userStore.clear()
  router.push('/login')
})

// === 子应用端 ===
// 1. 接收 Props
const { token, userInfo, env } = window.$wujie.props

// 2. 发送事件给主应用
window.$wujie.bus.$emit('user-action', { type: 'click', target: 'export-btn' })

// 3. 监听主应用广播
window.$wujie.bus.$on('theme-changed', (theme) => {
  document.documentElement.setAttribute('data-theme', theme)
})
```

**面试加分点：**
- **Props 单向下发**：主应用是数据源，子应用只读不写，避免双向耦合
- **Bus 事件总线**：松耦合通信，子应用之间不直接调用
- **不滥用 Bus**：高频数据走 Props，低频事件走 Bus
- 你在 Li People 中实际就是这套：登录态走 Props，员工选中联动走 Bus

## 十二、流式响应处理（结合理想同事）

### 场景
理想同事 Agent 对话中，AI 回复是流式的——一个字一个字往外吐。需要处理：实时输出、请求中断、错误重试。

### 实现 — SSE 流式接收

```js
class ChatStream {
  constructor() {
    this.controller = null  // AbortController，用于中断
    this.buffer = ''        // 累积的回复
    this.onChunk = null     // 每收到一段回调
    this.onDone = null      // 全部完成回调
    this.onError = null
  }

  async send(message) {
    // 如果有进行中的请求，先中断
    this.abort()

    this.controller = new AbortController()
    this.buffer = ''

    try {
      const res = await fetch('/api/chat', {
        method: 'POST',
        body: JSON.stringify({ message }),
        signal: this.controller.signal
      })

      // SSE 流式读取
      const reader = res.body.getReader()
      const decoder = new TextDecoder()

      while (true) {
        const { done, value } = await reader.read()
        if (done) break

        const text = decoder.decode(value, { stream: true })
        // 解析 SSE 格式：data: {...}\n\n
        const lines = text.split('\n').filter(l => l.startsWith('data:'))
        for (const line of lines) {
          const data = JSON.parse(line.slice(5))
          if (data.content) {
            this.buffer += data.content
            this.onChunk?.(data.content, this.buffer)
          }
          if (data.done) {
            this.onDone?.(this.buffer)
            return
          }
        }
      }
    } catch (e) {
      if (e.name === 'AbortError') return  // 主动中断不算错误
      this.onError?.(e)
    }
  }

  abort() {
    this.controller?.abort()
    this.controller = null
  }
}

// 组件中使用
const chat = new ChatStream()
chat.onChunk = (chunk, full) => {
  replyText.value = full  // 实时更新 UI
}
await chat.send('帮我请个假')
```

**面试加分点：**
- **AbortController** 中断——用户切走或重新提问时立即停止旧请求
- **TextDecoder stream:true** 处理跨 chunk 的中文截断
- **SSE 格式解析**——`data: {...}\n\n` 是标准 SSE 格式
- 这就是你理想同事项目里"多端流式能力封装"的核心

## 十三、iframe 嵌入与双向通信（结合理想同事）

### 场景
理想同事被嵌入业务系统的 iframe 中，需要和宿主系统双向通信——接收宿主的上下文（当前在哪个页面），向宿主返回操作结果。

### 实现 — postMessage 双向通信

```js
// === 宿主系统（外层）===
class HostBridge {
  constructor(iframeEl, targetOrigin) {
    this.iframe = iframeEl
    this.targetOrigin = targetOrigin  // 严格限制 origin，防恶意接收
    this.handlers = new Map()
    
    window.addEventListener('message', this.handleMessage.bind(this))
  }

  // 向 iframe 内发送消息
  send(type, payload) {
    this.iframe.contentWindow.postMessage(
      { type, payload, source: 'host' },
      this.targetOrigin
    )
  }

  // 接收 iframe 内的消息
  on(type, handler) {
    this.handlers.set(type, handler)
  }

  handleMessage(e) {

    if (e.origin !== this.targetOrigin) return

  }
}

    this.handlers = new Map()

    this.handlers.set(type, handler)
```

```js
class ComponentLoader {
  constructor(cdnBase) {
    this.cdnBase = cdnBase  // 'https://cdn.example.com/components'
    this.cache = new Map()  // version+name → module
  }

  async load(name, version) {
    const cacheKey = `${name}@${version}`
    
    // 1. 命中缓存
    if (this.cache.has(cacheKey)) {
      return this.cache.get(cacheKey)
    }

    // 2. 按版本号从 CDN 加载
    const url = `${this.cdnBase}/${version}/${name}.js`
    const module = await import(/* @vite-ignore */ url)
    
    this.cache.set(cacheKey, module.default)
    return module.default
  }
}

  },
  {
    id: 'msg_002',
    type: 'leave-request-form',
    version: '1.3.0',  // ← 后来版本
    props: { ... }
  }
]
```

## 十五、JWT 鉴权 SDK（结合出入预约 NestJS）

### 场景

### 实现 — 请求拦截器 + Token 刷新

```js
class AuthSDK {
  constructor() {
    this.accessToken = localStorage.getItem('access_token')
    this.refreshToken = localStorage.getItem('refresh_token')
    this.refreshing = null  // 进行中的刷新 Promise（去重）
  }

  // 给 fetch 加鉴权头 + 401 自动刷新
  async request(url, options = {}) {
    const res = await fetch(url, {
      ...options,
      headers: {
        'Authorization': `Bearer ${this.accessToken}`,
        ...options.headers
      }
    })

    // 401 → 尝试刷新 Token，重试一次
    if (res.status === 401) {
      await this.refresh()
      return fetch(url, {
        ...options,
        headers: {
          'Authorization': `Bearer ${this.accessToken}`,
          ...options.headers
        }
      })
    }

    return res
  }

  // Token 刷新（带去重——多个请求同时 401 只发一次刷新）
  async refresh() {
    // 如果已经在刷新了，复用同一个 Promise
    if (this.refreshing) return this.refreshing

    this.refreshing = (async () => {
      const res = await fetch('/api/auth/refresh', {
        method: 'POST',
        body: JSON.stringify({ refreshToken: this.refreshToken })
      })
      
      if (!res.ok) {
        // refreshToken 也过期了 → 跳登录页
        this.logout()
        throw new Error('请重新登录')
      }

      const { accessToken, refreshToken } = await res.json()
      this.setTokens(accessToken, refreshToken)
    })()

    try {
      await this.refreshing
    } finally {
      this.refreshing = null  // 清理
    }
  }

  setTokens(access, refresh) {
    this.accessToken = access
    this.refreshToken = refresh
    localStorage.setItem('access_token', access)
    localStorage.setItem('refresh_token', refresh)
  }

  logout() {
    this.accessToken = null
    this.refreshToken = null
    localStorage.removeItem('access_token')
    localStorage.removeItem('refresh_token')
    location.href = '/login'
  }
}

// 全局实例
export const auth = new AuthSDK()

// 业务代码使用
const res = await auth.request('/api/reservations', { method: 'GET' })
```

**面试加分点：**
- **Token 刷新去重**——`refreshing` Promise 复用，多个并发请求 401 只发一次刷新
- **重试一次**——刷新完用新 Token 重发原请求
- **refreshToken 也过期** → 跳登录页
- 这就是你 Li People + 出入预约共用鉴权 SDK 的核心

### 场景
出入预约项目中，预约单状态流转：草稿 → 待审批 → 已通过 → 已完成（含驳回/取消分支）。

### 实现 — 有限状态机

```js
// 状态定义
const STATES = {
  DRAFT: 'draft',
  PENDING: 'pending',       // 待审批
  APPROVED: 'approved',     // 已通过
  REJECTED: 'rejected',     // 已驳回
  COMPLETED: 'completed',   // 已完成
  CANCELLED: 'cancelled'    // 已取消
}

// 状态转移图
const TRANSITIONS = {
  [STATES.DRAFT]: {
    submit: STATES.PENDING,
    cancel: STATES.CANCELLED
  },
  [STATES.PENDING]: {
    approve: STATES.APPROVED,
    reject: STATES.REJECTED,
    cancel: STATES.CANCELLED
  },
  [STATES.APPROVED]: {
    complete: STATES.COMPLETED,
    cancel: STATES.CANCELLED
  },
  [STATES.REJECTED]: {
    resubmit: STATES.PENDING,
    cancel: STATES.CANCELLED
  },
  // 终态：COMPLETED、CANCELLED — 没有出口
}

class StateMachine {
  constructor(initialState, transitions) {
    this.state = initialState
    this.transitions = transitions
    this.listeners = []
  }

  can(action) {
    return Boolean(this.transitions[this.state]?.[action])
  }

  dispatch(action) {
    const nextState = this.transitions[this.state]?.[action]
    if (!nextState) {
      throw new Error(`非法操作：${this.state} 状态下不能执行 ${action}`)
    }
    const prevState = this.state
    this.state = nextState
    this.listeners.forEach(fn => fn(prevState, nextState, action))
  }

  onTransition(fn) {
    this.listeners.push(fn)
  }
}

// 使用
const order = new StateMachine(STATES.DRAFT, TRANSITIONS)
order.onTransition((from, to, action) => {
  console.log(`${from} → ${to} (${action})`)
  // 这里调后端接口持久化状态
})

order.dispatch('submit')    // draft → pending
order.dispatch('approve')  // pending → approved
order.dispatch('complete')  // approved → completed

// 非法操作
try {
  order.dispatch('submit')  // completed 状态不能 submit
} catch (e) {
  console.error(e.message)
}
```

**面试加分点：**
- **状态机核心**：state + transitions + dispatch
- **非法操作防御**：终态不能转移，避免了"已完成订单又被提交"这种 bug
- **onTransition 监听**：每次状态变化可以触发副作用（接口持久化、UI 更新）
- 适合任何状态流转场景：订单、审批流、签到流程

### 场景

```js
class LazyTree {
  constructor(container, fetchData) {
    this.container = container
    this.fetchData = fetchData  // (parentId) => Promise<children>
    this.nodeMap = new Map()    // id → node
    this.expandedSet = new Set()  // 已展开的节点
  }

  async init(rootId) {
    const root = await this.fetchData(rootId)
    this.render(root, 0)
  }

  async toggleExpand(node) {
    if (this.expandedSet.has(node.id)) {
      // 收起
      this.expandedSet.delete(node.id)
      this.container.removeChilds(node.id)
    } else {
      // 展开：先显示 loading，再异步加载
      this.expandedSet.add(node.id)
      this.showLoading(node)
      
      const children = await this.fetchData(node.id)
      this.hideLoading(node)
      this.render(children, node.level + 1, node.id)
    }
  }

  render(nodes, level, parentId) {
    nodes.forEach(node => {
      this.nodeMap.set(node.id, { ...node, level, parentId })
      const el = this.createNodeElement(node, level)
      this.container.appendChild(el, parentId)
    })
  }

  createNodeElement(node, level) {
    const el = document.createElement('div')
    el.className = 'tree-node'
    el.style.paddingLeft = `${level * 20}px`
    el.innerHTML = `
      <span class="arrow">${node.hasChildren ? '▶' : ''}</span>
      <span class="label">${node.name}</span>
      <span class="count">${node.memberCount} 人</span>
    `
    if (node.hasChildren) {
      el.querySelector('.arrow').addEventListener('click', () => this.toggleExpand(node))
    }
    return el
  }
}

// 使用
const tree = new LazyTree(container, async (parentId) => {
  const res = await fetch(`/api/org/children?parentId=${parentId}`)
  return res.json()
})
await tree.init('root')
```

**面试加分点：**
- **懒加载**：只渲染顶层，点击展开才请求子节点
- **已展开缓存**：`expandedSet` 避免重复请求
- **缩进控制**：`paddingLeft: level * 20px`，视觉层级
- 这就是你在组织信息管理平台用 Ant G6 实现的"数据懒加载"核心思路

## 十九、跨 Tab 状态同步（结合 Li People）

### 场景
Li People 中用户开了多个 Tab，在 Tab A 退出登录，其他 Tab 要同步退出。

### 实现 — storage 事件 + 事件总线

```js
class CrossTabSync {
  constructor() {
    this.handlers = new Map()
    window.addEventListener('storage', this.handleStorage.bind(this))
  }

  // 广播给其他 Tab
  broadcast(type, payload) {
    // 用 Date.now() 保证值会变，否则 storage 事件不触发
    localStorage.setItem(`__cross_tab__${type}`, JSON.stringify({
      type, payload, timestamp: Date.now()
    }))
    // 本 Tab 自己也手动触发
    this.dispatch(type, payload)
  }

  // 监听其他 Tab 的广播
  on(type, handler) {
    if (!this.handlers.has(type)) {
      this.handlers.set(type, [])
    }
    this.handlers.get(type).push(handler)
  }

  handleStorage(e) {
    if (!e.key?.startsWith('__cross_tab__')) return
    if (!e.newValue) return  // 被删除时不处理

    const { type, payload } = JSON.parse(e.newValue)
    this.dispatch(type, payload)
  }

  dispatch(type, payload) {
    this.handlers.get(type)?.forEach(fn => fn(payload))
  }
}

// 使用
const sync = new CrossTabSync()

// 主应用入口
sync.on('logout', () => {
  userStore.clear()
  router.push('/login')
})

sync.on('theme-change', (theme) => {
  document.documentElement.setAttribute('data-theme', theme)
})

// 退出登录时
function logout() {
  userStore.clear()
  sync.broadcast('logout', {})  // 广播给所有 Tab
}
```

**面试加分点：**
- **storage 事件不在本 Tab 触发**——broadcast 时要手动 dispatch 一次
- **值不变不触发**——加 `timestamp: Date.now()` 保证每次都变
- **key 前缀 `__cross_tab__`**——避免和业务 storage 冲突
- 你在 Li People 多子应用中可以扩展成"主应用退出，所有子应用跟着退出"

## 二十、虚拟列表进阶（不定高度）

### 场景
组织架构人员列表，每人有头像、姓名、职位——高度不固定（50/80/100px 都可能）。简单的固定高度虚拟列表用不了。

### 实现 — 不定高度虚拟列表

```js
class DynamicVirtualList {
  constructor(container, options) {
    this.container = container
    this.itemEstHeight = options.itemEstHeight || 50  // 预估高度
    this.buffer = options.buffer || 5
    this.positions = []        // 每项的实际位置 [{top, bottom, height}]
    this.items = []
    
    // 占位的 phantom div + 实际 content div
    this.phantom = document.createElement('div')
    this.content = document.createElement('div')
    this.phantom.style.position = 'relative'
    this.content.style.position = 'absolute'
    this.content.style.top = '0'
    this.container.style.overflow = 'auto'
    this.container.style.position = 'relative'
    
    this.container.appendChild(this.phantom)
    this.phantom.appendChild(this.content)
    
    this.container.addEventListener('scroll', this.render.bind(this))
  }

  setItems(items) {
    this.items = items
    // 初始化预估位置
    this.positions = items.map((_, i) => ({
      index: i,
      top: i * this.itemEstHeight,
      bottom: (i + 1) * this.itemEstHeight,
      height: this.itemEstHeight
    }))
    // 占位总高度
    this.phantom.style.height = `${this.positions[this.positions.length - 1].bottom}px`
    this.render()
  }

  // 二分查找 startIndex
  getStartIndex(scrollTop) {
    let low = 0, high = this.positions.length - 1
    while (low <= high) {
      const mid = Math.floor((low + high) / 2)
      const midBottom = this.positions[mid].bottom
      if (midBottom === scrollTop) return mid + 1
      if (midBottom < scrollTop) low = mid + 1
      else if (midBottom > scrollTop) high = mid - 1
    }
    return low
  }

  render() {
    const scrollTop = this.container.scrollTop
    const viewHeight = this.container.clientHeight

    const start = Math.max(0, this.getStartIndex(scrollTop) - this.buffer)
    let end = start
    let bottom = this.positions[start]?.top || 0
    while (bottom < scrollTop + viewHeight + this.buffer * this.itemEstHeight && end < this.items.length) {
      bottom = this.positions[end].bottom
      end++
    }

    // 渲染可视区域
    const visibleItems = this.items.slice(start, end)
    this.content.style.transform = `translateY(${this.positions[start]?.top || 0}px)`
    this.content.innerHTML = visibleItems.map((item, i) => `
      <div class="item" data-index="${start + i}">${this.renderItem(item)}</div>
    `).join('')

    // 渲染后更新实际高度（修正预估）
    this.updatePositions(start)
  }

  updatePositions(startIndex) {
    const itemEls = this.content.querySelectorAll('.item')
    itemEls.forEach((el, i) => {
      const index = startIndex + i
      const realHeight = el.getBoundingClientRect().height
      const oldHeight = this.positions[index].height
      const diff = realHeight - oldHeight
      
      // 更新当前项
      this.positions[index].height = realHeight
      this.positions[index].bottom = this.positions[index].top + realHeight
      
      // 更新后面所有项
      for (let j = index + 1; j < this.positions.length; j++) {
        this.positions[j].top = this.positions[j - 1].bottom
        this.positions[j].bottom = this.positions[j].top + this.positions[j].height
      }
    })
    
    // 更新总高度
    this.phantom.style.height = `${this.positions[this.positions.length - 1].bottom}px`
  }

  renderItem(item) {
    return `
      <img src="${item.avatar}" />
      <div>${item.name}</div>
      <div>${item.title}</div>
    `
  }
}
```

**面试加分点：**
- **预估高度 + 实际测量修正**：初始用预估，渲染后用 `getBoundingClientRect` 测真实高度
- **二分查找 startIndex**：1万条数据从 O(n) 降到 O(log n)
- **位置缓存**：`positions` 数组记录每项的 top/bottom/height
- 这是真正高级前端会被问到的虚拟列表题

## 二十一、RAG 检索增强完整实现（Agent 工程必会）

### 场景
用户提问"理想汽车请假流程是什么"→ 系统从企业知识库检索相关文档 → 喂给 LLM 生成准确回答。这是 2026 年 Agent 前端面试的必考题。

### 完整实现 — 前端 + 轻量后端

```ts
// === 1. 文档切片（Chunking）===

class ChunkingService {
  // 策略1：固定长度切片
  chunkBySize(text: string, chunkSize = 500, overlap = 50): string[] {
    const chunks = []
    for (let i = 0; i < text.length; i += chunkSize - overlap) {
      chunks.push(text.slice(i, i + chunkSize))
    }
    return chunks
  }

  // 策略2：语义切片（按段落，推荐）
  chunkBySemantic(text: string, minSize = 200, maxSize = 800): string[] {
    const paragraphs = text.split(/\n\s*\n/)
    const chunks = []
    let current = ''

    for (const p of paragraphs) {
      if ((current + p).length > maxSize) {
        if (current) chunks.push(current)
        current = p
      } else if (current.length >= minSize) {
        chunks.push(current)
        current = p
      } else {
        current += '\n\n' + p
      }
    }
    if (current) chunks.push(current)
    return chunks
  }

  // 策略3：父子块切割（面试高频考点）
  // 大块用于检索（更多上下文），小块用于喂 LLM（省 token）
  chunkParentChild(text: string): { parent: string; children: string[] }[] {
    const parentChunks = this.chunkBySemantic(text, 800, 1500)
    return parentChunks.map(parent => ({
      parent,
      children: this.chunkBySize(parent, 200, 30)  // 子块更小
    }))
  }
}

// 面试追问："为什么用父子块切割？"
```

```ts
    //   body: JSON.stringify({ model: 'text-embedding-3-small', input: text })
    // })
    // return res.data[0].embedding
    return new Array(512).fill(0).map(() => Math.random())  // mock
  }

  // 余弦相似度
  cosineSimilarity(a: number[], b: number[]): number {
    let dot = 0, normA = 0, normB = 0
    for (let i = 0; i < a.length; i++) {
      dot += a[i] * b[i]
      normA += a[i] * a[i]
      normB += b[i] * b[i]
    }
    return dot / (Math.sqrt(normA) * Math.sqrt(normB))
  }

  // 向量检索
  async search(query: string, topK = 10): Promise<{ chunk: string; score: number }[]> {
    const queryEmbedding = await this.embed(query)
    const results: { chunk: string; score: number }[] = []

    for (const [chunk, embedding] of this.embeddings) {
      const score = this.cosineSimilarity(queryEmbedding, embedding)
      results.push({ chunk, score })
    }

    return results.sort((a, b) => b.score - a.score).slice(0, topK)
  }
}
```

```ts
// === 3. BM25 关键词检索（混合检索的另一路）===

class BM25Service {
  private docs: string[] = []
  private termFreqs: Map<string, Map<string, number>> = new Map()
  private docFreq: Map<string, number> = new Map()
  private avgDocLength = 0
  private k1 = 1.5
  private b = 0.75

  index(docs: string[]) {
    this.docs = docs
    let totalLength = 0

    docs.forEach((doc, docId) => {
      const terms = this.tokenize(doc)
      const freq = new Map<string, number>()
      totalLength += terms.length

      for (const term of terms) {
        freq.set(term, (freq.get(term) || 0) + 1)
      }
      this.termFreqs.set(String(docId), freq)

      for (const term of new Set(terms)) {
        this.docFreq.set(term, (this.docFreq.get(term) || 0) + 1)
      }
    })

    this.avgDocLength = totalLength / docs.length
  }

  search(query: string, topK = 10): { doc: string; score: number }[] {
    const queryTerms = this.tokenize(query)
    const scores: { doc: string; score: number }[] = []

    this.docs.forEach((doc, docId) => {
      let score = 0
      const docLength = this.tokenize(doc).length
      const freq = this.termFreqs.get(String(docId))!

      for (const term of queryTerms) {
        const tf = freq.get(term) || 0
        const df = this.docFreq.get(term) || 0
        const idf = Math.log((this.docs.length - df + 0.5) / (df + 0.5) + 1)
        const tfScore = (tf * (this.k1 + 1)) / (tf + this.k1 * (1 - this.b + this.b * (docLength / this.avgDocLength)))
        score += idf * tfScore
      }

      scores.push({ doc, score })
    })

    return scores.sort((a, b) => b.score - a.score).slice(0, topK)
  }

  private tokenize(text: string): string[] {
    return text.toLowerCase().split(/\s+|[，。、！？；：]/).filter(Boolean)
  }
}
```

```ts
// === 4. 混合检索 + Rerank（核心流程）===

class RAGService {
  constructor(
    private chunking: ChunkingService,
    private vectorSearch: VectorSearchService,
    private bm25: BM25Service
  ) {}

  // 完整 RAG 流程
  async retrieve(query: string): Promise<string[]> {
    // 1. 向量检索（语义相似）
    const vectorResults = await this.vectorSearch.search(query, 20)

    // 2. BM25 检索（关键词匹配）
    const bm25Results = this.bm25.search(query, 20)

    // 3. 混合排序（加权融合，向量 0.6 + BM25 0.4）
    const hybridScores = new Map<string, number>()
    const VECTOR_WEIGHT = 0.6
    const BM25_WEIGHT = 0.4

    // 归一化 + 加权
    const maxVector = Math.max(...vectorResults.map(r => r.score), 1)
    const maxBM25 = Math.max(...bm25Results.map(r => r.score), 1)

    vectorResults.forEach(({ chunk, score }) => {
      hybridScores.set(chunk, (score / maxVector) * VECTOR_WEIGHT)
    })
    bm25Results.forEach(({ doc, score }) => {
      hybridScores.set(doc, (hybridScores.get(doc) || 0) + (score / maxBM25) * BM25_WEIGHT)
    })

    // 4. Rerank 精排（取 top 20 → 精排到 top 5）
    const candidates = Array.from(hybridScores.entries())
      .sort((a, b) => b[1] - a[1])
      .slice(0, 20)
      .map(([chunk]) => chunk)

    return this.rerank(query, candidates, 5)
  }
```

### 面试加分点

1. **父子块切割**：检索用子块（精度高），喂 LLM 用父块（上下文完整）
2. **混合检索权重**：6:4 不是固定值，要根据业务数据 benchmark 调参
