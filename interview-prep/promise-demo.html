Promise 执行流程可视化

模拟浏览器真实执行顺序：同步代码 → 微任务 → 宏任务

示例代码
console.log('A: 同步开始');

const p = new Promise((resolve) => {
  console.log('B: Promise executor 同步');
  resolve('hello');
});

p.then(v => console.log('D: then 1 -', v));

setTimeout(() => {
  console.log('F: 宏任务');
}, 0);

p.then(v => console.log('E: then 2 -', v));

console.log('C: 同步结束');
