## 术语精确性红灯（二面最容易被抓）

- ❌ 事件循环不参与渲染 → 渲染是事件循环的一部分
- ❌ PatchFlags 是注释节点 → 是位运算数字
- ❌ Fn.prototype 是 Object.prototype → Fn.prototype 是 Fn 自己的原型对象
- ❌ 异步组件 render 返回 Promise → 是 defineAsyncComponent 的 loader 返回 Promise
- ❌ computed 返回 Promise 会报错 → 会缓存 Promise 对象本身，拿不到值
- ❌ effect 的值变 undefined → effect 是副作用函数，重新执行后读到新值
- ❌ provide/inject 不适合实时响应 → 它是响应式的，问题是数据流不透明

## 标准答案速查

**1. ref vs reactive 底层**

`reactive` 用 Proxy 代理对象，靠 `track/trigger` + `targetMap` 收集依赖，惰性深层代理 + WeakMap 缓存；`ref` 用 RefImpl 实例包装原始值（`get/set value`），对象值内部调 `toReactive → reactive`，依赖挂在 RefImpl 自己的 dep。整体替换时 ref 走 setter 不丢响应式，reactive 返回的是 Proxy 本身、重新赋值就绕过代理。

**2. Vue3 diff / compiler**

PatchFlags 是位运算枚举（TEXT=1、CLASS=2 等），编译期作为 `createVNode` 第四参数，diff 只处理标记位；Block 的 `dynamicChildren` 只收集动态节点，`v-if/v-for` 是结构边界会开新 Block；Vue2 是双端 diff（无 LIS），Vue3 是快速 diff（先处理前后缀，中间乱序段用 key 建索引 + 最长递增子序列 LIS 最小化移动）。

**3. 调度 / nextTick**

`nextTick` 用 `Promise.then`（微任务），同一次事件里多次 setState 通过队列去重、合并成一次渲染；Vue2 有降级链 `Promise → MutationObserver → setImmediate → setTimeout`。`watch` 的 `flush: pre/post/sync` 是 watch 回调的执行时机，与 nextTick 无关。

**4. 组件通信 / v-model**

父子 `props + emit`；跨层 `provide/inject`（响应式，但数据流不透明、不可追踪）；全局 Pinia。`v-model` 等价于 `:prop="x" @update:prop="x=$event"`，`defineModel` 省略手写 props/emits/模板绑定，多 v-model 拆成多个 prop + event。

**5. computed / watch**

computed 是惰性求值 + `_dirty` 脏标志：依赖变只置 dirty，访问 `.value` 才重算，依赖不变返回缓存；`watch` 的 `deep=true` 用 traverse 递归收集深层依赖，`immediate=true` 创建后立即执行一次。computed 必须是纯函数，异步/副作用用 watch。

**6. keep-alive / Teleport / Suspense**

keep-alive 缓存「组件实例 + vnode + DOM」，内部 cache + keys 做 LRU，切走移入隐藏容器不 unmount，`onActivated` 首次挂载和切回都触发；Teleport 内容渲染到目标节点但上下文/生命周期仍属当前组件；`defineAsyncComponent` 的 loader 返回 Promise，Suspense 在 resolve 前显示 fallback。

**7. 大屏性能**

`shallowRef` / `markRaw` 让第三方实例（ECharts/G6）不被深层代理，避免性能和 this 问题；`v-memo` 是「依赖数组不变就跳过子树渲染」，不是「销毁复用」；`IntersectionObserver` 进入视口才初始化，滚出 `dispose()` 释放，限制同时实例数。

**8. SSR / 水合**

SSR 首屏 FCP/LCP 快、SEO 好，代价是 TTFB 可能更慢 + 服务器成本 + 水合复杂；hydration 是客户端复用服务端 DOM、挂事件和响应式，mismatch 是两端渲染结果不一致；不稳定值（随机数、`Date.now()`）放 `onMounted`/`<ClientOnly>`，稳定 id 用 `useId`。

**9. 浏览器渲染管线**

外链 CSS 阻塞渲染 + 阻塞其后 JS 执行，但不阻塞 HTML 解析；同步 JS 阻塞 HTML 解析（可能 `document.write`）；DOM + CSSOM → Render 树，`display:none` 不在、`visibility:hidden` 在（占位）；`transform/opacity` 是合成属性，只改合成层、跳过 layout/paint。

**10. 回流重绘 / 强制同步布局**

改几何属性（宽高/边距/位置）触发回流，改颜色/背景触发重绘；回流必伴随重绘。强制同步布局 = 写样式后立刻读几何属性，浏览器为返回准确值被迫同步 layout。`requestAnimationFrame` 在下一帧渲染前执行，配合「先读后写」合并到一次布局。

**11. 事件循环与渲染**

渲染是事件循环的一部分：宏任务 → 清空微任务（含新产生的，直到空）→ 渲染步骤（rAF）→ 下一个宏任务。微任务套娃会让队列永远清不空、轮不到渲染，从而阻塞页面。

**12. requestIdleCallback / 内存**

`requestIdleCallback` 在帧末空闲时执行，`deadline.timeRemaining()` 返回剩余空闲毫秒、`didTimeout` 表示是否超时强制。内存泄漏常见原因：全局变量、未清理定时器、未解绑事件、detached DOM、Map/Set 强引用；用 Performance 看内存曲线 + Memory Heap Snapshot 定位。

**13. 四大存储对比**

Cookie 约 4KB、可设过期、随请求发送、Domain/Path 控制作用域；localStorage 约 5MB、永久、同源跨 Tab 共享、不随请求；sessionStorage 约 5MB、当前标签页、同源 + 标签页隔离、不随请求；IndexedDB 容量大、永久、同源、异步、支持索引和事务。SameSite：Strict/Lax/None。

**14. HTTP 缓存 / Service Worker**

强缓存 `Cache-Control: max-age` / `Expires`；协商缓存 `ETag + If-None-Match`、`Last-Modified + If-Modified-Since`。`no-store` 不缓存、`no-cache` 缓存但每次验证、`must-revalidate` 过期后强制验证。Service Worker 是独立线程、可编程缓存，相比 HTTP 缓存可自定义策略但需处理版本更新。

**15. IndexedDB**

异步、非关系型、存结构化对象和二进制、支持索引+事务+游标；本质是「浏览器内数据库」，localStorage 是「同步 KV 字符串存储」。场景：文件分片断点续传存 hash/进度、大屏/报表离线缓存、Blob 二进制存储。

**16. DNS / TCP**

DNS 缓存层级：浏览器缓存 → OS/hosts → 本地 DNS → 根 → 顶级 → 权威；递归查询（本地代查）vs 迭代查询（逐级返回下一级）。三次握手确认双方收发能力 + 同步 ISN，两次无法确认客户端发送被收且防历史连接。`dns-prefetch` 只解析 DNS，`preconnect` 解析 + TCP + TLS。

**17. CORS**

简单请求：GET/HEAD/POST + 三种表单 Content-Type + 安全头；非简单请求先发 OPTIONS 预检，响应 `Access-Control-Allow-Origin/Methods/Headers/Max-Age/Credentials`。跨域是浏览器拦截响应。JSONP 只支持 GET、需服务端配合、安全风险大、错误处理弱。

**18. this 指向**

四条绑定：默认（`fn()` → window/undefined）、隐式（`obj.fn()`）、显式（call/apply/bind）、new；箭头函数定义时捕获外层 this。`arguments[0]()` 的 this 是 arguments 对象。

**19. 原型链 / new**

`obj.__proto__ === Object.getPrototypeOf(obj)`，`new Fn().__proto__ === Fn.prototype`。new 四步：创建对象 → 原型指向 Fn.prototype → 以新对象为 this 执行 Fn → 返回对象则用它否则返回新对象。instanceof 沿原型链向上找构造函数的 prototype。

**20. 事件循环输出题**

`1, 4, 7, 9, 10, 5, 8, 6, 2, 3`。关键：await 恢复的微任务（8）在 then 链第二个 then（6）之前；setTimeout 里 Promise.then 的微任务（3）在宏任务末尾执行。
