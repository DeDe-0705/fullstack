## 一、Vue

- 🔴 **ref 与 reactive 底层**：`RefImpl.dep` vs `targetMap`；`ref({})` 内部调 `toReactive → reactive`；惰性代理 + `WeakMap` 缓存
- 🔴 **diff / 编译器**：`PatchFlags` 是位运算数字（不是注释节点）；`v-if/v-for` 为什么开新 Block；Vue2 双端 diff vs Vue3 快速 diff（前后缀 + 中间段 LIS）
- 🟡 **调度**：`nextTick` 用 `Promise.then`（微任务）；`watch` 的 `flush: pre/post/sync` 与 nextTick 无关
- 🟡 **组件通信**：`provide/inject` 是响应式的，但数据流不透明；`defineModel` 省略手写 props/emits/模板绑定
- 🟡 **computed/watch**：computed 惰性求值 + `_dirty`；`deep = traverse`；`immediate`；computed 返回 Promise 拿不到值
- 🟡 **内置组件**：keep-alive 缓存「实例 + vnode + DOM」+ LRU；`onActivated` 首次挂载也触发；Teleport 上下文不断；`defineAsyncComponent` 的 loader（不是 render）返回 Promise
- 🟡 **性能**：`shallowRef` vs `markRaw`；`v-memo` 是「依赖不变跳过渲染」不是「销毁复用」；图表滚出要 `dispose`
- 🟡 **SSR**：hydration / mismatch；不稳定值放 `onMounted` / `<ClientOnly>` / `useId`

## 二、浏览器原理

- 🟡 **渲染管线**：CSS 阻塞渲染 + 阻塞其后 JS；同步 JS 阻塞解析；`display:none` 不在 Render 树、`visibility:hidden` 在
- 🔴 **强制同步布局**：读写分离；rAF 是「渲染前 + 先读后写」不是「放不同帧」
- 🔴 **事件循环含渲染**：宏任务 → 清空微任务 → 渲染（rAF）→ 下一个宏任务；微任务套娃会阻塞渲染
- 🟡 **requestIdleCallback**：帧末空闲执行；`timeRemaining` / `didTimeout`
- 🟡 **内存泄漏**：detached DOM；用 Performance + Memory Heap Snapshot 定位

## 三、存储

- 🟡 **四维对比**：Cookie/localStorage/sessionStorage/IndexedDB 的容量、生命周期、作用域、是否随请求
- 🟡 **作用域**：localStorage 同源跨 tab 共享；sessionStorage 同源 + 标签页隔离；`SameSite` 三值
- 🟡 **HTTP 缓存**：强缓存 `max-age/Expires`；协商缓存 `ETag/If-None-Match`、`Last-Modified/If-Modified-Since`；`must-revalidate` vs `no-cache`
- 🟡 **Service Worker**：可编程缓存 vs HTTP 缓存自动管理；离线/推送/后台同步
- 🟡 **IndexedDB**：异步、支持索引/事务/二进制；断点续传存 hash 和进度、大屏/报表离线缓存

## 四、网络与 HTTP（不含 TLS）
