 # 迭代器与生成器

 ## 一、迭代器（Iterator）

 ### 一句话：一种协议，对象实现了 `next()` 方法，返回 `{ value, done }`，就叫迭代器。

 ```js
 // 手写一个迭代器
 function createIterator(arr) {
   let index = 0;
   return {
     next() {
       if (index < arr.length) {
         return { value: arr[index++], done: false };
       }
       return { value: undefined, done: true };
     },
   };
 }

 const it = createIterator(["a", "b", "c"]);
 it.next(); // { value: 'a', done: false }
 it.next(); // { value: 'b', done: false }
 it.next(); // { value: 'c', done: false }
 it.next(); // { value: undefined, done: true }
 ```

 ### 可迭代对象（Iterable）

 对象实现了 `Symbol.iterator` 方法，返回一个迭代器，就能被 `for...of` 消费。

 ```js
 const obj = {
   data: [1, 2, 3],
   [Symbol.iterator]() {
     let i = 0;
     return {
       next: () => {
         if (i < this.data.length) return { value: this.data[i++], done: false };
         return { value: undefined, done: true };
       },
     };
   },
 };

 for (const v of obj) console.log(v); // 1 2 3
 [...obj]; // [1, 2, 3]
 ```

 **天然可迭代：** Array、String、Map、Set、arguments、NodeList、TypedArray

 **面试小问：** `for...of` 和 `for...in` 有什么区别？
 - `for...of`：遍历可迭代对象的值（走迭代器协议）
 - `for...in`：遍历对象的可枚举属性键（包括原型链）

 ## 二、生成器（Generator）

 ### 一句话：用 `function*` 声明的函数，可以暂停和恢复执行。调用返回一个迭代器对象。

 ```js
 function* gen() {
   yield 1;
   yield 2;
   yield 3;
 }

 const g = gen();
 g.next(); // { value: 1, done: false }
 g.next(); // { value: 2, done: false }
 g.next(); // { value: 3, done: false }
 g.next(); // { value: undefined, done: true }
 ```

 ### yield 的双向通信

 `yield` 不仅能往外传值，外面的 `next(arg)` 还能往里传值：

 ```js
 function* twoWay() {
   const a = yield "先给你 a";
   console.log("收到:", a);
   const b = yield "再给你 b";
   console.log("收到:", b);
 }

 const g = twoWay();
 g.next();        // { value: '先给你 a', done: false }
 g.next("hello"); // 收到: hello   -> { value: '再给你 b', done: false }
 g.next("world"); // 收到: world   -> { value: undefined, done: true }
 ```

 注意：第一个 `next()` 传参无效，因为此时还没到任何 `yield` 语句。

 ### 经典应用场景

 **1. 异步流程控制（async/await 的前身）**

 ```js
 function* asyncFlow() {
   const data1 = yield fetch("/api/1");
   const data2 = yield fetch("/api/2");
   return [data1, data2];
 }

 // 需要一个执行器（co 库做的事）
 function run(gen) {
   const g = gen();
   function next(v) {
     const { value, done } = g.next(v);
     if (done) return value;
     Promise.resolve(value).then(next);
   }
   next();
 }
 ```

 这也是为什么面试爱问**"async/await 和 Generator 的关系"**——async/await 就是 Generator + 自动执行器的语法糖。

 **2. 惰性求值 / 无限序列**

 ```js
 function* fibonacci() {
   let [a, b] = [0, 1];
   while (true) {
     yield a;
     [a, b] = [b, a + b];
   }
 }

 const fib = fibonacci();
 fib.next().value; // 0
 fib.next().value; // 1
 fib.next().value; // 1
 fib.next().value; // 2
 // 不会一次性计算整个序列，按需取值
 ```

 **3. 遍历树形结构**

 ```js
 function* traverse(node) {
   yield node.value;
   for (const child of node.children) {
     yield* traverse(child); // yield* 委托给另一个生成器
   }
 }
 ```

 ## 三、yield* 委托

 `yield*` 把迭代委托给另一个可迭代对象：

 ```js
 function* outer() {
   yield 1;
   yield* [2, 3, 4];  // 展开数组
   yield* inner();     // 展开另一个生成器
   yield 5;
 }

 function* inner() {
   yield "a";
   yield "b";
 }

 [...outer()]; // [1, 2, 3, 4, "a", "b", 5]
 ```

 ## 四、面试速查

 | 问题 | 答案要点 |
|------|----------|
| 迭代器协议是什么？ | 对象有 `next()` 方法，返回 `{ value, done }` |
| 可迭代协议？ | 对象有 `Symbol.iterator` 方法，返回迭代器 |
| `for...of` vs `for...in` | `of` 走迭代器取值；`in` 遍历可枚举属性键（含原型） |
| Generator 函数怎么用？ | `function*` + `yield`，调用返回迭代器，可暂停恢复 |
| `yield` 能传参吗？ | 能，`next(arg)` 将 arg 传给上一个 `yield` 的返回值 |
| async/await 和 Generator 的关系？ | async/await 是 Generator + 自动执行器的语法糖，`await` ≈ `yield` |
| `yield*` 有什么用？ | 委托给另一个可迭代对象或生成器 |
