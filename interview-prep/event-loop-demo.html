Event Loop 可视化

逐步执行，观察调用栈、微任务队列、宏任务队列的变化

调用栈 微任务队列 宏任务队列
示例代码
// 点击「逐步执行」查看每一步的队列状态
console.log('1: 同步');

setTimeout(() => {
  console.log('2: 宏任务');
}, 0);

Promise.resolve().then(() => {
  console.log('3: 微任务');
  setTimeout(() => {
    console.log('4: 宏任务(来自微任务)');
  }, 0);
});

console.log('5: 同步');
