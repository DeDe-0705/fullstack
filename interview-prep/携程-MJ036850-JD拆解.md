1. **统一 B 端前端框架**：系统设计 + 开发迭代 + 在项目中落地优化（框架 Owner 角色）
2. **AI Coding 工具链**：「需求评审 → 开发 → 验证」全链路 AI 开发能力，目标 = 中小项目全自动化开发、大型项目高效率开发（这是岗位的差异化核心，大概率也是面试主战场）
3. B 端用户体验提升（追赶国际市场营销头部企业的 B 端体验）

## 三、匹配度评估

**强项（重点输出）：**
- AI 工程化实战（Claude Code/MCP）—— 直接命中 JD 第 2 条主线，市面上大多数候选人没有这块深度
- 无界微前端 —— 「统一 B 端框架」叙事的最佳素材：多团队、多技术栈、独立部署、通信/沙箱/样式隔离
- React 19 + NestJS 全栈 —— Express 是 NestJS 默认底层，能讲清中间件/请求生命周期即可平移
- 性能优化体系已有成文弹药

**需补强（冲刺重点）：**
1. **Harness / Agent Loop / Workflow 三个名词的标准定义 + 一线实践语境**（JD 原文点名，必考）
2. **「需求评审→开发→验证」全链路叙事**：把自己的 AI Coding 实践串成这条链，每一环有具体做法和卡点解决
3. **B 端体验的度量**：效率提升怎么量化（任务时长、操作步数、NPS），避免只讲技术
4. **国际化 i18n/l10n**：国际业务背景，可能被问多语言方案（react-i18next、ICU MessageFormat、RTL、时区/货币）
5. **Express 基础快过一遍**：中间件洋葱模型 vs Koa、路由、错误处理、与 NestJS 的关系
