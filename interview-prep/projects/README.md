## 面试策略

### 第一梯队（必问，重点准备）

**Li People 门户** — 微前端是你的王牌
- 无界 vs qiankun 选型理由
- 四大核心能力（鉴权/路由/通信/性能）
- G6 组织架构图实现
- 工程化建设（CI/CD、版本管理、组件库）

**理想同事** — AI Agent 是 2026 年最热门
- SSE 流式渲染架构
- 动态组件 CDN 加载
- Iframe 跨应用通信
- 多端兼容方案

### 第二梯队（高频，深入准备）

**出入预约** — AI 工程化差异化
- Claude Code Skill 体系
- Sub-Agent 协同研发
- 前后端并行开发流程
- 状态机设计

**组织信息管理** — 跨端 + 可视化
- G6 可视化优化
- Taro 双端架构
- 细粒度权限管控
- 双向无限下钻联动

### 第三梯队（补充，点到为止）

**理想文化** — 相对轻量
- 瀑布流布局
- 大文件分片上传
- 视频播放组件封装

## 面试话术模板

### 开场介绍（30秒）

> "我在理想汽车主要负责职能业务线的前端工作，主导了 Li People 门户的微前端架构落地，支持人事、组织、薪酬等多业务模块独立开发部署。同时负责理想同事 AI Agent 项目的前端架构，实现了流式渲染、动态组件加载、跨应用通信等核心能力。最近在用 Claude Code + Sub-Agent 搭建 AI 驱动的研发流程，提升团队交付效率。"

### 项目深挖（按优先级）

1. **微前端**：必问，重点准备选型理由、四大能力实现细节
2. **AI Agent**：2026 年最热门，重点准备流式渲染、动态组件
3. **AI 工程化**：差异化优势，重点准备 Sub-Agent 协同、效率提升数据
4. **跨端**：高频考点，重点准备代码复用策略、Taro 工程体系
5. **可视化**：体现复杂交互能力，重点准备 G6 优化方案
